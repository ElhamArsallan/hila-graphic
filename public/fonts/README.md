# RokhFaNum Font Family Assets Directory

Place your 12 `.woff2` font files directly into this directory (`public/fonts/`).

### Required Files:
1. `RokhFaNum-HairLine.woff2` (Weight: 100)
2. `RokhFaNum-Thin.woff2` (Weight: 200)
3. `RokhFaNum-ExtraLight.woff2` (Weight: 250)
4. `RokhFaNum-Light.woff2` (Weight: 300)
5. `RokhFaNum-Normal.woff2` (Weight: 350)
6. `RokhFaNum-Regular.woff2` (Weight: 400)
7. `RokhFaNum-Medium.woff2` (Weight: 500)
8. `RokhFaNum-SemiBold.woff2` (Weight: 600)
9. `RokhFaNum-Bold.woff2` (Weight: 700)
10. `RokhFaNum-ExtraBold.woff2` (Weight: 800)
11. `RokhFaNum-UltraBold.woff2` (Weight: 850)
12. `RokhFaNum-Black.woff2` (Weight: 900)

Once placed here, the website will automatically load and apply `RokhFaNum` across all headings, body text, and RTL/LTR content.
